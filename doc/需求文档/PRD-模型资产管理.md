# PRD — 模型资产管理

## 1. 概述

模型资产管理模块负责模型全生命周期管理，涵盖基础模型、场景模型、组合模型、碰撞规则和数据集五大类资产的统一维护。对应路由 `/assets`。

## 2. 角色定义

| 角色 | 权限 |
|------|------|
| **分析师** | 查看模型资产详情、检索匹配模型、查看模型成熟度 |
| **系统管理员** | 新增/编辑/删除模型资产、管理碰撞规则、数据集版本管理、审核模型上下架 |

## 3. 用户故事

### 资产检索与查看
1. 作为分析师，我可以按侦测阶段（行动策划/人员集结/装备筹措/物流运输/临期准备）筛选模型
2. 作为分析师，我可以按模型形态（基础模型/场景模型/组合模型）和成熟度等级（L1-L4）过滤
3. 作为分析师，我点击模型卡片查看详情：名称、版本、场景标签、成熟度、创建时间、关联规则

### 资产录入与维护
4. 作为管理员，我可以新增模型资产，填写名称、分类、场景标签、成熟度等级、关联数据集
5. 作为管理员，我可以编辑已有模型的元信息（标签、成熟度升级、关联关系）
6. 作为管理员，我可以下架/删除过时的模型资产

### 碰撞规则管理
7. 作为管理员，我可以查看碰撞沉淀的规则列表及其置信度
8. 作为管理员，我可以手动新增/编辑/禁用碰撞规则

### 数据集管理
9. 作为管理员，我可以上传和管理数据集，查看其版本历史和关联模型

## 5. 交互逻辑

### 筛选流程
1. 用户选择/切换筛选条件 → 列表和网格实时更新
2. 支持多选筛选（如同时选择"场景模型"+"L3成熟度"）
3. 搜索支持按名称/标签模糊匹配

### 资产详情
1. 点击模型卡片 → 弹出详情对话框，展示完整元信息
2. 详情包括：基本信息、关联规则列表、版本历史时间线
3. 管理员模式显示编辑/删除操作按钮

### 三级分类体系
- **维度1 — 侦测阶段**：行动策划类 / 人员集结类 / 装备筹措类 / 物流运输类 / 临期准备类
- **维度2 — 模型形态**：基础模型 (通用) / 场景模型 (微调后) / 组合模型 (碰撞产物)
- **维度3 — 成熟度等级**：L1-实验验证 / L2-场景验证 / L3-业务可用 / L4-生产就绪

## 6. 功能描述

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 模型列表 | 表格/卡片双视图，支持多维度筛选和搜索 | P0 |
| 模型详情 | 弹窗展示完整元信息、关联规则、版本历史 | P0 |
| 模型CRUD | 管理员新增/编辑/删除模型，字段校验 | P1 |
| 规则管理 | 碰撞规则列表、新增/编辑/禁用、置信度管理 | P1 |
| 数据集管理 | 数据集上传、版本关联、使用统计 | P2 |
| 成熟度升级 | 工作流驱动：L1→L2→L3→L4，需管理员审批 | P2 |

## 7. 节点设计（审批流）

### 模型成熟度升级审批

```
分析师发起升级申请
       │
       ▼
┌──────────────┐
│ 提交升级材料  │ ← 附验证报告 / 评估报告
│ (分析师)      │
└──────┬───────┘
       │
       ▼
┌──────────────┐     驳回
│ 管理员审批    │──────────▶ 回到原等级 + 附驳回原因
└──────┬───────┘
       │ 通过
       ▼
┌──────────────┐
│ 成熟度升级    │
│ L(n) → L(n+1)│
└──────────────┘
```
