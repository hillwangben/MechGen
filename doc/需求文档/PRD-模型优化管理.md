# PRD — 模型优化管理

## 1. 概述

模型优化管理覆盖从数据集构建到模型训练、验证、评估的完整优化链路。对应路由 `/training`（训练工作台）和 `/evaluation`（评估仪表盘）。系统是"建议者"，分析师是"决策者"。

## 2. 角色定义

| 角色 | 职责 |
|------|------|
| **分析师** | 发起优化任务、确认优化方案、查看训练进度、审核验证结果、决策是否进入碰撞 |
| **系统/优化智能体** | 自动推荐优化方案、执行训练、生成验证报告、输出评估对比 |

## 3. 用户故事

### 优化启动
1. 作为分析师，当模型分配不满足需求时，系统自动推荐优化方案（从哪个基础模型开始、预期耗时）
2. 作为分析师，我确认优化方案后系统自动跳转到训练工作台

### 训练配置
3. 作为分析师，我在训练工作台左侧配置面板选择：基础模型、数据集、超参数预设、计算资源
4. 作为分析师，我点击"开始训练"，系统启动后台训练任务并实时推送状态

### 训练监控
5. 作为分析师，我实时查看训练日志、损失曲线、GPU 使用率
6. 作为分析师，训练完成后我收到通知，可查看模型产物

### 模型验证
7. 作为分析师，我查看交叉验证结果（准确率/召回率/F1）
8. 作为分析师，我查看场景回放和边界测试通过率

### 模型评估
9. 作为分析师，我在评估仪表盘查看多模型对比雷达图
10. 作为分析师，我查看自动生成的评估报告，决定是否满足需求
11. 作为分析师，优化不满足时可返回调整参数重新训练

### 优化审批
12. 优化满足需求后，分析师确认 → 进入优化完成状态，模型可用于碰撞

## 5. 交互逻辑

### 训练工作流状态机
```
  [配置参数] → [开始训练] → [训练中] → [训练完成] → [验证中] → [评估报告]
       │            │           │            │           │
       └─ 可重置 ───┘    └─ 可中止 ──┘   └─ 可重试 ──┘  └─ 满足/继续优化
```

### 训练实时交互
1. 配置面板任一参数变更 → 预估耗时动态更新
2. 点击"开始训练" → 日志区开始滚动，损失曲线每秒刷新
3. 训练中可点击"中止" → 保存断点，下次可恢复
4. 训练完成 → 配置面板锁定，自动触发验证

### 评估交互
1. 选择对比模型（A/B 框） → 雷达图实时更新
2. 切换场景回放筛选 → 表格动态过滤
3. 评估报告为自动生成，支持下载 PDF

## 6. 功能描述

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 优化方案推荐 | 根据场景需求自动推荐基础模型+数据集组合 | P0 |
| 训练配置 | 基础模型/数据集选择、超参数预设、资源选择 | P0 |
| 训练监控 | 实时日志、损失曲线、GPU/耗时指标 | P0 |
| 模型验证 | 交叉验证、场景回放、边界测试结果展示 | P1 |
| 评估仪表盘 | 多模型对比雷达图、指标卡片、对比表格 | P1 |
| 评估报告 | 自动生成+下载，含建议 | P2 |
| 断点续训 | 保存训练断点，支持恢复 | P2 |
