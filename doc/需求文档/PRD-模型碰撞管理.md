# PRD — 模型碰撞管理

## 1. 概述

模型碰撞管理负责多模型联合推理、规则提取沉淀和新模型资产生成。碰撞在统一工作空间的画布上触发，碰撞结果独立管理。对应画布中的"碰撞框"节点和碰撞规则管理。

## 2. 角色定义

| 角色 | 职责 |
|------|------|
| **分析师** | 选择参与碰撞的模型、确认碰撞方案、审查碰撞结果和沉淀规则、决定是否入库 |
| **碰撞统筹智能体** | 调度多模型推理、融合结果、提取碰撞规则、生成新模型资产 |

## 3. 用户故事

### 碰撞发起
1. 作为分析师，我在画布上选择 2 个或更多优化完成的模型，右键创建碰撞框
2. 作为分析师，我点击碰撞框跳转到碰撞详情页，查看参与模型列表
3. 作为分析师，我确认碰撞参数（推理模式、融合策略）后点击"开始碰撞"

### 碰撞执行与监控
4. 作为分析师，我实时查看碰撞推理进度（各模型推理状态、中间结果）
5. 作为分析师，碰撞采用时间相关性 + 空间关联性分析
6. 作为分析师，碰撞完成后收到通知

### 碰撞结果审查
7. 作为分析师，我查看碰撞结果：关联强度、置信度、建议行动
8. 作为分析师，我查看自动提取的碰撞规则（如"同行人出现 + 频繁通信 → 高危"）
9. 作为分析师，我可以接受/拒绝/编辑自动提取的规则

### 规则沉淀与资产生成
10. 作为分析师，我确认碰撞结果 → 规则自动入库，关联场景标签
11. 作为分析师，碰撞生成的新模型（组合模型）作为资产进入模型库
12. 作为分析师，新模型可在下一轮分配中检索匹配，形成闭环

### 碰撞历史
13. 作为分析师，我可查看历史碰撞记录及其结果
14. 作为分析师，我可对比不同碰撞方案的结果差异

## 5. 交互逻辑

### 碰撞流程状态机
```
  [选择模型] → [创建碰撞框] → [确认参数] → [碰撞中] → [结果生成] → [审查确认]
       │                          │           │           │
       └── 可增减模型 ─────────────┘   └─ 可中止 ─┘   └─ 可驳回 ─┘
```

### 画布中创建碰撞框
1. Shift+左键多选 2+ 个优化完成模型
2. 右键画布 → 弹出菜单："将已选 X 个模型加入碰撞框"
3. 点击 → 生成红色虚线碰撞框，嵌入选中模型
4. 点击碰撞框 → 跳转碰撞详情页

### 碰撞推理交互
1. 四个阶段卡片（模型推理→模型推理→结果融合→碰撞结果）依次点亮
2. 每个阶段完成 → 卡片状态切换（等待/进行中/完成）
3. 全部完成 → 碰撞结果面板展开，提取规则列表弹出

### 规则确认交互
1. 提取的规则以列表展示，每条含置信度
2. 分析师逐条确认/编辑/拒绝
3. 确认的规则 → 自动入库，关联场景标签和碰撞ID

## 6. 功能描述

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 碰撞框创建 | 画布右键创建碰撞框，嵌入多模型 | P0 |
| 碰撞参数配置 | 推理模式、融合策略选择 | P0 |
| 碰撞执行 | 多模型联合推理，阶段状态追踪 | P0 |
| 碰撞结果展示 | 关联强度、置信度、建议行动 | P0 |
| 规则提取 | 自动提取碰撞规则，人工确认入库 | P0 |
| 新模型生成 | 碰撞产物入库为组合模型 | P1 |
| 碰撞历史 | 历史记录查询、方案对比 | P1 |
| 规则回馈闭环 | 沉淀规则反馈到模型优化流程 | P2 |
