# 反无技战法生成模块 — 项目总需求

## 项目背景

反无人机领域面临日益复杂的威胁场景，传统技战法依赖人工分析经验，效率低、不可复制。本模块旨在构建一套智能化系统，将分析师的经验判断与 AI 模型能力结合，实现从基础模型到场景化可用模型的自动化生产与持续演进。

**核心问题**：
- 模型资产分散，缺乏统一检索和匹配机制
- 单一模型无法覆盖复杂场景，需要多模型协同碰撞
- 模型优化依赖人工调参，缺乏自动化工作流
- 分析决策过程无沉淀，经验无法复用

**行业现状**：反无人机领域的数据分析和模型应用处于早期阶段，尚未形成标准化的技战法生产体系。

## 目标用户

| 角色 | 职责 | 核心诉求 |
|------|------|---------|
| **分析师** | 发起分析任务、评估模型匹配度、确认优化/碰撞方案 | 快速检索匹配模型、一键触发优化碰撞、决策过程可追溯 |
| **系统管理员** | 管理模型资产库、维护碰撞规则、监控引擎状态 | 资产全生命周期管理、规则沉淀复用、系统健康监控 |

## 用户故事

### 模型分配
1. 作为分析师，我输入场景需求（如"同行人识别"），系统自动检索匹配的模型资产，告知匹配度及推荐理由
2. 作为分析师，当无匹配模型时，系统推荐从基础模型开始优化训练，并给出预期耗时
3. 作为分析师，我确认或拒绝推荐方案，系统记录决策并进入下一步

### 模型优化
4. 作为分析师，我选择需要优化的模型，跳转到训练工作台查看训练参数和进度
5. 作为分析师，优化完成后我查看验证结果（交叉验证、场景回放、边界测试），决定是否满足需求
6. 作为分析师，优化不满足时可继续迭代或调整参数

### 模型碰撞
7. 作为分析师，我选择 2+ 个模型，触发碰撞分析，系统进行多模型联合推理
8. 作为分析师，碰撞完成后我查看碰撞结果和自动沉淀的规则，确认是否入库
9. 作为分析师，碰撞生成的新模型可作为资产进入下一轮分配和优化循环

### 统一工作空间
10. 作为分析师，我在画布上通过拖拽和连线可视化编排模型流程
11. 作为分析师，我通过自然语言描述需求，问答面板与画布实时联动
12. 作为分析师，我可以随时查看任务阶段状态、模型数量和引擎健康度

## 业务结构（一级业务）

### 1. 模型分配
从基础模型库和场景模型库中检索匹配当前分析场景的模型资产。
- 语义搜索模型资产 + 匹配度评估
- 推荐理由生成 + 不满足分析
- 用户确认门禁

### 2. 模型优化
对不满足需求的模型进行自动化训练优化。
- 数据集构建（采集、标注、增强、版本管理）
- 模型训练（基础模型加载、超参搜索、分布式训练、模型转换）
- 模型验证（交叉验证、对抗验证、场景回放、边界测试）
- 模型评估（多维度评估、对比分析、报告生成）

### 3. 模型碰撞
多模型联合推理，沉淀碰撞规则，生成新模型资产。
- 推理调度 + 结果融合
- 规则提取沉淀（如："同行人出现 + 频繁通信 → 高危"）
- 新模型资产生成 + 闭环反馈

### 4. 模型资产管理
模型全生命周期管理，包括基础模型、场景模型、组合模型、碰撞规则、数据集。

### 四层技术架构
```
接入层 (可视化界面 + 问答交互)
  → 统一任务网关 (解析 → 拆分 → 上下文构建 → 调度)
    → 智能体协同引擎 (优化统筹 → 执行智能体集 → 碰撞统筹 → 事件总线)
      → 模型资产层 (基础模型库 + 场景模型库 + 碰撞规则库 + 数据集仓库)
```

## 布局方式

### 统一工作空间 (主界面)
```
┌──────────────────────────────────────────────────────────────────────────────┐
│ TopBar (48px)                                         任务ID │ 保存 │ 用户  │
├──────────┬─────────────────┬───────────────────────┬────────────────────────┤
│ SideNav  │ 模型组件面板     │    模型画布 (中央)      │   问答面板 (380px)     │
│ (60px)   │ (240px)         │   - 决策树流程布局       │   - 自然语言交互       │
│ 图标模式  │ - 分类树形列表   │   - 模型→优化→碰撞→生成  │   - 状态查询           │
│          │ - 基础模型       │   - ●圆形模型嵌入框架   │   - 参数调整           │
│          │ - 场景模型       │   - 点击框架跳转工作台  │   - 确认门禁           │
│          │ - 组合模型       │                      │   (SSE/WS 流式)        │
├──────────┴─────────────────┴───────────────────────┴────────────────────────┤
│ 状态栏 (32px)                               阶段指示器 │ 进度 │ 引擎状态     │
└──────────────────────────────────────────────────────────────────────────────┘
```
- 四栏布局：侧边导航(60px) + 模型组件面板(240px) + 画布区域(自适应) + 问答面板(380px)
- 模型组件面板支持拖拽到画布创建节点
- **画布布局 — 决策树流程结构**：
  - 自上而下的决策树结构，不体现内部架构分层
  - 模型为圆形节点（直径60px），直接嵌入优化框/碰撞框内部，框之间用直线连接
  - 业务流程：优化框(内含原始模型) ─→ 碰撞框(内含优化产物) ─→ 碰撞新模型（优化产物仅在碰撞框内体现，不重复）
  - 节点类型区分：
    - 模型节点（圆形 ●）：蓝色实线=原始模型、橙色虚线=生成模型
    - 框架节点（虚线大容器）：紫色=优化框、红色=碰撞框，框内2列网格排列，尺寸按模型数动态计算
  - 点击框架节点可跳转对应工作台（优化/碰撞），操作记录与画布同源
  - 连线采用直线样式
  - 滚轮缩放 · 拖拽平移
- 画布与问答面板双向联动,通过 Pinia store 共享状态
- 支持面板折叠/展开

### 模型组件面板
- 分类展示可用模型和操作节点：
  - 基础模型 — 通用预训练模型
  - 场景模型 — 场景微调模型
  - 组合模型 — 碰撞产物模型
  - 操作节点 — 模型优化、模型碰撞、验证评估
- 支持拖拽到画布创建节点
- 分类可折叠/展开

### 独立全屏界面 (训练工作台 / 评估仪表盘)
- 顶栏 + 侧边导航保留,中央内容区全宽展示
- 训练工作台: 左侧配置面板 + 右侧实时日志/图表


### 视觉元素
- **背景**: 深色底 + 网格线图案 + SVG 噪点纹理 + 径向霓虹光晕
- **CRT 扫描线**: 全局横向扫描线叠加层 (`body::after`)
- **边框**: 直角设计 (`border-radius: 0`),1-2px 霓虹色边框 + 外发光
- **角标装饰**: 面板/卡片四角 L 形支架 (赛博朋克 HUD 标志性特征)

- **按钮**: 直角、霓虹发光边框、悬浮时外发光增强
- **数据展示**: 等宽字体 + 霓虹文字发光 (HUD 读数风格)
- **动画**: 脉冲呼吸 (neon-pulse)、状态指示灯闪烁、边框跑马灯、故障效果
