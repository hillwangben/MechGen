# PRD — 统一工作空间

## 1. 概述

统一工作空间是反无技战法生成模块的主界面，采用四栏布局（侧边导航 + 模型组件面板 + 模型画布 + 问答面板），提供可视化画布编排与自然语言问答的双通道交互。以决策树流程结构驱动模型分配→优化→碰撞的技术链路，构建以智能体为驱动、以人机协作为交互模式、以模型进化为目标的闭环工作系统。对应路由 `/workspace`。

## 2. 角色定义

| 角色 | 职责 |
|------|------|
| **分析师** | 发起分析任务、检索匹配模型、拖拽编排模型流程、触发优化/碰撞、确认各阶段门禁 |
| **系统 (AI 助手)** | 语义检索模型、推荐优化方案、回答分析师问题、确认门禁 |
| **智能体引擎** | 后台执行优化训练、碰撞推理、规则沉淀等计算任务 |

## 3. 用户故事

### 模型分配 — 问答交互
1. 作为分析师，我在问答面板输入场景需求（如"我需要分析同行人识别场景"），助手自动检索匹配模型
2. 作为分析师，我查看助手推荐的模型列表和匹配度评分
3. 作为分析师，匹配模型自动出现在画布上，或需优化的模型一并展示

### 模型分配 — 拖拽操作
4. 作为分析师，我从左侧组件面板拖拽模型节点到画布
5. 作为分析师，我在画布上排列和连线节点，构建分析流程

### 画布编排
6. 作为分析师，我 Shift+左键多选模型 → 右键创建优化框/碰撞框
7. 作为分析师，优化框和碰撞框之间自动连线，形成决策树
8. 作为分析师，我点击框架节点跳转到对应的训练工作台或碰撞详情页
9. 作为分析师，我滚轮缩放和拖拽平移画布，查看完整流程

### 门禁确认
10. 作为分析师，每个阶段完成后（分配/优化/碰撞），系统弹出确认门禁
11. 作为分析师，我确认方案后流程自动推进到下一阶段

### 状态监控
12. 作为分析师，我通过状态栏实时查看当前阶段、模型数量、引擎状态

## 5. 交互逻辑

### 双通道协同（画布 ↔ 问答）
```
  问答面板                        画布
  ┌──────────┐               ┌──────────────┐
  │"分析同行人" │──检索匹配──▶  │ 自动创建模型节点│
  │          │               │              │
  │ 显示检索结果│◀───同步────  │ 模型在画布展示  │
  └──────────┘               └──────┬───────┘
                                    │
   ┌──────────┐                     │
   │"创建优化框"│───触发操作────────▶ │
   │          │                     ▼
   │ 确认门禁  │◀───等待确认────  ┌──────────────┐
   └──────────┘                  │ 创建优化框     │
                                 │ 嵌入选中模型   │
                                 └──────────────┘
```

### 画布操作
| 操作 | 交互 | 说明 |
|------|------|------|
| 选中模型 | 左键点击 | 模型圆变为实心色 |
| 多选模型 | Shift+左键 | 支持跨框多选 |
| 右键菜单 | 右键画布 | 显示"已选 X 个模型"，可创建优化框/碰撞框 |
| 创建优化框 | 右键菜单 | 生成紫色虚线框，嵌入选中模型 |
| 创建碰撞框 | 右键菜单 | 生成红色虚线框，嵌入选中模型 |
| 框架连线 | 自动 | 优化框→碰撞框直线连接 |
| 跳转工作台 | 点击框架 | 优化框→训练工作台、碰撞框→碰撞详情 |
| 缩放 | 滚轮 | 0.3x~2.5x |
| 平移 | 左键拖拽空白 | 自由平移 |
| 删除 | Del 键 | 删除选中节点/框架+子节点+连线 |

### 门禁确认流程
```
模型分配完成 → [确认] → 模型优化完成 → [确认] → 碰撞完成 → [确认] → 新模型入库
     │                    │                   │
     └── 拒绝: 重新分配 ──┘  └── 拒绝: 重新优化 ──┘  └── 拒绝: 调整碰撞 ──┘
```

## 7. 节点设计（画布节点）

### 模型节点（圆形 ●）
- **类型**：`model-circle` (原始) / `model-circle-generated` (生成)
- **直径**：60px
- **原始模型**：蓝色实线圆 `#00d4ff`，透明填充，选中后 50% 透明度填充
- **生成模型**：橙色虚线圆 `#ff8c00`，15% 透明度填充，选中后加深
- **标签**：圆心文字，宋体 12px

### 优化框架节点（虚线容器）
- **形状**：矩形虚线框，紫色 `#b366ff`
- **尺寸**：按内部模型数量动态计算，2列网格排列
  - 宽 = 22×2 + 2×60 + 20 = 184px
  - 高 = 40 (标题栏) + rows×74 + 36 (底部输出区)
- **标题**：拼接模型名称，如"目标检测 + 文本理解"
- **输出标签**：框底标注"→ 输出优化模型"
- **点击跳转**：`/training`

### 碰撞框架节点（虚线容器）
- **形状**：矩形虚线框，红色 `#ff3860`
- **标题**：拼接模型名称
- **输出标签**：框底标注"→ 输出碰撞新模型"
- **点击跳转**：碰撞详情页

### 连线
- **样式**：直线，1px 青色 `#00d4ff`
- **方向**：优化框 → 碰撞框 → 碰撞新模型
- **标签**：可选标注操作类型
