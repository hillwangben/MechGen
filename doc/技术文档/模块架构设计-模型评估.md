# 模块架构设计 — 模型评估 (evaluation)

> 所属项目：[MechGen 反无技战法生成模块](../CLAUDE.md)
> 总体架构：[总体架构设计](总体架构设计.md)

## 1. 模块定位

模型评估模块为优化和碰撞产出的模型提供多维度评估能力，包括指标计算、横向对比、报告生成。评估结果是用户确认门禁的关键输入，决定是否进入下一阶段。

## 2. 后端设计（`modules/evaluation/`）

### 2.1 API 路由

| 方法 | 路径 | 说明 | 独立可用 |
|------|------|------|---------|
| POST | `/api/v1/evaluation/metrics` | 计算模型评估指标 | ✅ |
| POST | `/api/v1/evaluation/compare` | 多模型横向对比 | ✅ |
| GET | `/api/v1/evaluation/reports` | 查询评估报告列表 | ✅ |
| GET | `/api/v1/evaluation/reports/{id}` | 获取评估报告详情 | ✅ |
| POST | `/api/v1/evaluation/reports/generate` | 生成评估报告 | ✅ |

### 2.2 Service 层

```python
# modules/evaluation/service.py

class EvaluationService:
    """评估业务逻辑 — 可被前端直接调用，也可被智能体通过 skill 调用"""

    async def compute_metrics(self, req: MetricsRequest) -> MetricsResult:
        """计算多维度评估指标"""
        ...

    async def compare_models(self, req: CompareRequest) -> ComparisonReport:
        """多模型横向对比分析"""
        ...

    async def list_reports(self, filters: ReportFilters) -> list[EvaluationReport]:
        """查询评估报告列表"""
        ...

    async def get_report(self, report_id: str) -> EvaluationReport:
        """获取报告详情"""
        ...

    async def generate_report(self, req: GenerateReportRequest) -> EvaluationReport:
        """生成评估报告"""
        ...
```

### 2.3 Schema 定义

| Schema | 字段 | 说明 |
|--------|------|------|
| `MetricsRequest` | model_id, dimensions, test_dataset_id | 指标计算请求 |
| `MetricsResult` | model_id, dimensions, scores, radar_data | 指标计算结果 |
| `DimensionScore` | dimension, score, baseline, details | 单维度评分 |
| `CompareRequest` | model_ids, dimensions | 对比请求 |
| `ComparisonReport` | models, dimensions, rankings, highlights | 对比报告 |
| `RadarChartData` | labels, datasets | 雷达图数据 |
| `GenerateReportRequest` | model_ids, report_type, include_comparison | 报告生成请求 |
| `EvaluationReport` | id, model_ids, metrics, comparisons, conclusions, created_at | 评估报告实体 |
| `ReportFilters` | model_id, report_type, date_range | 报告过滤条件 |

### 2.4 数据模型

```python
# modules/evaluation/model.py

class EvaluationTask(Base):
    """评估任务表"""
    __tablename__ = "evaluation_tasks"

    id: Mapped[str]
    model_ids: Mapped[list[str]]         # 被评估的模型ID列表
    dimensions: Mapped[list[str]]        # 评估维度
    status: Mapped[str]                  # pending/running/completed/failed
    result: Mapped[dict | None]          # 评估结果 JSON
    created_at: Mapped[datetime]
    updated_at: Mapped[datetime]


class EvaluationReport(Base):
    """评估报告表"""
    __tablename__ = "evaluation_reports"

    id: Mapped[str]
    task_id: Mapped[str | None]          # 关联评估任务
    model_ids: Mapped[list[str]]         # 涉及模型
    report_type: Mapped[str]             # single/compare/comprehensive
    metrics: Mapped[dict]                # 指标数据 JSON
    comparisons: Mapped[dict | None]     # 对比数据 JSON
    conclusions: Mapped[list[str]]       # 结论列表
    created_at: Mapped[datetime]
    updated_at: Mapped[datetime]
```

## 3. 智能体设计（`agents/evaluation/`）

### 3.1 智能体列表

| 智能体 | 职责 | 调用的 service | 协作智能体 |
|--------|------|---------------|-----------|
| `metrics_analyzer` | 多维度指标计算（准确率、延迟、鲁棒性等），生成雷达图数据 | `evaluation.metrics` | — |

### 3.3 Skills

**multi-dimensional-eval**（`agents/evaluation/skills/multi-dimensional-eval/SKILL.md`）：

```markdown
---
name: multi-dimensional-eval
description: 设计评估维度，执行评估流程
allowed-tools: execute read_file
---

# 多维度评估技能

## 触发场景
当需要评估模型的综合表现时使用。

## 工作流程
1. 根据模型类型和场景确定评估维度（准确率、延迟、鲁棒性、泛化性等）
2. 构造 MetricsRequest，调用 evaluation.metrics API
3. 解析评估结果，生成雷达图数据
4. 标记不达标维度

## 评估维度
| 维度 | 说明 | 度量 |
|------|------|------|
| 准确率 | 模型预测正确率 | Precision/Recall/F1 |
| 延迟 | 推理响应时间 | P50/P95/P99 |
| 鲁棒性 | 对抗/噪声下的稳定性 | 下降率 |
| 泛化性 | 跨场景表现 | 场景间差异 |

## 输出格式
返回 MetricsResult，包含各维度评分和雷达图数据。
```

**report-generation**（`agents/evaluation/skills/report-generation/SKILL.md`）：

```markdown
---
name: report-generation
description: 生成结构化评估报告和对比分析
allowed-tools: execute read_file
---

# 报告生成技能

## 触发场景
当需要生成评估报告或模型对比分析时使用。

## 工作流程
1. 如果未提供指标数据，先调用 metrics_analyzer 计算指标
2. 构造 GenerateReportRequest，调用 evaluation.generate_report API
3. 如涉及多模型对比，调用 evaluation.compare API
4. 组织结论和建议

## 输出格式
返回 EvaluationReport，包含指标、对比、结论和建议行动。
```

## 4. 事件发布与订阅

| 事件方向 | 事件类型 | 说明 |
|---------|---------|------|
| 发布 | `task_completed` | 评估完成，报告可用 |
| 订阅 | `task_completed` (module=optimization) | 优化完成后触发评估 |
| 订阅 | `task_completed` (module=collision) | 碰撞完成后触发评估 |

## 5. 与其他模块的协作

```
调用方：
  report_generator → metrics_analyzer  计算评估指标（内部协作）

被调用方：
  optimization.optimizer → metrics_analyzer       优化完成后评估模型
  collision.collision_coordinator → metrics_analyzer 碰撞产物评估
  collision.collision_coordinator → report_generator 碰撞报告生成
```
